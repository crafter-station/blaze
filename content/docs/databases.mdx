| Method | Path | Notes |
| --- | --- | --- |
| `GET` | `/v1/databases` | List. No credentials included. |
| `POST` | `/v1/databases` | Create. Returns the connection string. |
| `GET` | `/v1/databases/:id` | Read one, with credentials. |
| `PATCH` | `/v1/databases/:id` | Rename, or set/clear `ttl_seconds`. |
| `DELETE` | `/v1/databases/:id` | Permanent. |

## Expiry

`ttl_seconds` names its unit deliberately: guessing wrong should give you a database that lives 24 hours rather than 24 seconds. Send `null` to clear an expiry; omit the field to leave it untouched.

```bash title="Clear an expiry"
curl -X PATCH https://blaze.crafter.run/v1/databases/$ID \
  -H "Authorization: Bearer $BLAZE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"ttl_seconds":null}'
```

## Engines

`engine` is one of the available engines below. It defaults to `postgres`.

```bash title="Create a MongoDB database"
curl -X POST https://blaze.crafter.run/v1/databases \
  -H "Authorization: Bearer $BLAZE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"engine":"mongo","name":"my-app"}'
```

The connection string comes back in the scheme each engine's drivers expect: `postgresql://`, `mysql://`, `mariadb://`, `mongodb://` (with `tls=true`), and `rediss://`. See [MongoDB](/docs/mongodb) for its connection options.
